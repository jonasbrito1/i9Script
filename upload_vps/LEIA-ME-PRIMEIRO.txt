⚙️ O QUE OS SCRIPTS FAZEM
--------------------------------------------------------------------------------

setup-vps.sh:
  • Atualiza sistema Ubuntu/Debian
  • Instala Docker + Docker Compose
  • Instala Nginx
  • Instala Certbot (para SSL)
  • Configura firewall
  • Cria estrutura de diretórios

deploy.sh:
  • Configura Nginx
  • Gera certificado SSL Let's Encrypt
  • Copia arquivos para locais corretos
  • Inicia containers Docker (MySQL + Backend)
  • Executa migrations do banco
  • Verifica saúde dos serviços

restart.sh:
  • Reinicia todos os containers
  • Útil após mudanças

logs.sh:
  • Visualiza logs em tempo real
  • logs.sh backend (só backend)
  • logs.sh mysql (só MySQL)


🏗️ ARQUITETURA DE PRODUÇÃO
--------------------------------------------------------------------------------

FRONTEND (React):
  ├─ Servido pelo Nginx
  ├─ Build otimizado e minificado
  ├─ Cache de assets (1 ano)
  └─ HTTPS com Let's Encrypt

BACKEND (Node.js):
  ├─ Roda em Docker container
  ├─ Proxy reverso via Nginx
  ├─ Socket.IO para real-time
  └─ API RESTful

DATABASE (MySQL 8.0):
  ├─ Container Docker isolado
  ├─ Dados persistentes em volume
  └─ Acesso local via porta 3306

NGINX:
  ├─ SSL/TLS (HTTPS)
  ├─ Proxy para backend
  ├─ Serve frontend estático
  └─ WebSocket support

📞 COMANDOS ÚTEIS PÓS-DEPLOY
--------------------------------------------------------------------------------

Ver status dos containers:
  docker ps

Ver logs em tempo real:
  bash /var/www/i9script/scripts/logs.sh

Reiniciar serviços:
  bash /var/www/i9script/scripts/restart.sh

Acessar MySQL:
  docker exec -it i9script-mysql-prod mysql -ui9script -p

Backup do banco:
  docker exec i9script-mysql-prod mysqldump -ui9script -p i9script_db > backup.sql

Restaurar backup:
  docker exec -i i9script-mysql-prod mysql -ui9script -p i9script_db < backup.sql
