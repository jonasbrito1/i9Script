================================================================================
                            ENDPOINTS DA API
================================================================================

🔐 Autenticação:
  POST   /api/auth/register        Registrar usuário
  POST   /api/auth/login           Login
  GET    /api/auth/me              Info usuário logado

🎫 Tickets (i9Help):
  GET    /api/tickets              Listar tickets
  POST   /api/tickets              Criar ticket
  GET    /api/tickets/:id          Detalhes ticket
  PATCH  /api/tickets/:id          Atualizar ticket
  POST   /api/tickets/:id/comments Adicionar comentário
  GET    /api/tickets/stats        Estatísticas

📊 Projetos:
  GET    /api/projects             Listar projetos
  POST   /api/projects             Criar projeto
  GET    /api/projects/:id         Detalhes projeto
  PATCH  /api/projects/:id         Atualizar projeto
  POST   /api/projects/:id/updates Adicionar update
  GET    /api/projects/stats       Estatísticas

📋 Kanban:
  GET    /api/kanban/:projectId    Obter board
  POST   /api/kanban/:projectId/cards  Criar card
  PATCH  /api/kanban/cards/:id     Atualizar card
  DELETE /api/kanban/cards/:id     Deletar card

👥 Usuários:
  GET    /api/users                Listar usuários
  PATCH  /api/users/:id            Atualizar usuário
