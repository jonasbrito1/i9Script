✅ APÓS UPLOAD - EXECUTAR NO SERVIDOR
--------------------------------------------------------------------------------

[ ] 1. TORNAR SCRIPTS EXECUTÁVEIS
    cd /var/www/i9script/scripts
    chmod +x *.sh

[ ] 2. EXECUTAR SETUP DO VPS
    bash setup-vps.sh

    (Instala Docker, Nginx, Certbot, etc)

[ ] 3. CONFIGURAR VARIÁVEIS DE AMBIENTE
    cd /var/www/i9script
    cp .env.example .env
    nano .env

    Alterar senhas!

[ ] 4. CONFIGURAR BACKEND ENV
    nano backend/.env.production

    Verificar:
    - JWT_SECRET
    - DB_PASSWORD (igual ao .env)
    - CORS_ORIGIN=https://i9script.com

[ ] 5. EXECUTAR DEPLOY
    bash /var/www/i9script/scripts/deploy.sh

    Responder "s" quando perguntar sobre DNS

[ ] 6. VERIFICAR SERVIÇOS
    docker ps

    Deve mostrar containers rodando:
    - i9script-mysql-prod
    - i9script-backend-prod

[ ] 7. TESTAR ACESSO
    - Frontend: https://i9script.com
    - API: https://i9script.com/api
    - Login: admin@i9script.com / admin123
