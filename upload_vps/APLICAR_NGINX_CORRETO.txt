================================================================================
DIFERENÇAS PRINCIPAIS DA CONFIGURAÇÃO CORRETA
================================================================================

❌ ERRADO (configuração antiga):
server {
    root /var/www/i9script/frontend;  ← AQUI ESTÁ O PROBLEMA!

    location ^~ /guiadoempreendedor {
        alias /var/www/i9script/guia_do_empreendedor/frontend;
        # O alias é ignorado por causa do root global acima
    }
}

✅ CORRETO (nova configuração):
server {
    # SEM root aqui no nível do server!

    location ^~ /guiadoempreendedor {
        alias /var/www/i9script/guia_do_empreendedor/frontend;
        # Agora o alias funciona corretamente
    }

    location / {
        root /var/www/i9script/frontend;  ← root DENTRO da location
        # Só afeta esta location específica
    }
}
