-----------------------------

2. Editar senhas (IMPORTANTE):

   Altere as senhas padrão:

   - MYSQL_PASSWORD

3. Verificar arquivo .env do backend:

- Configurar Nginx
- Gerar certificado SSL (Let's Encrypt)
- Copiar arquivos para locais corretos

🆘 TROUBLESHOOTING
--------------------------------------------------------------------------------

Problema: Certificado SSL não gerou
Solução: Verifique se DNS está propagado e execute:
  certbot --nginx -d i9script.com -d www.i9script.com

Problema: Containers não iniciam
Solução: Ver logs específicos:
  docker logs i9script-backend-prod
  docker logs i9script-mysql-prod

Problema: Erro de conexão com banco
Solução: Verificar variáveis de ambiente e reiniciar:
  bash scripts/restart.sh

Problema: Frontend retorna 502 Bad Gateway
Solução: Verificar se backend está rodando:
  docker ps
  docker logs i9script-backend-prod
