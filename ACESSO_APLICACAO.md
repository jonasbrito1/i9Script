## 🛠️ Comandos Úteis

### Backend (Porta 5000)
```bash
cd server
npm run dev      # Desenvolvimento com hot-reload
npm run build    # Build para produção
npm run migrate  # Executar migrações do banco
```

### Frontend (Porta 3001)
```bash
cd client
npm start        # Iniciar servidor de desenvolvimento
npm run build    # Build para produção
```

### Banco de Dados
- Host: localhost
- Porta: 3306
- Banco: i9script_db
- Usuário: root
